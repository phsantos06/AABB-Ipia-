# AABB Ipiaú — Site Institucional

Landing page do clube **AABB Ipiaú-BA** (Associação Atlética Banco do Brasil): estrutura, planos de sócio, eventos e contato.

**Acesse:** https://aabb-ipia.vercel.app

![Página inicial do site AABB Ipiaú](hero-fachada.jpeg)

## Destaques
- Hero com chamada para associação e reserva de eventos
- Números do clube, estrutura, planos e perguntas frequentes
- Botão flutuante de WhatsApp
- Responsivo, leve e sem dependências

## Stack
HTML · CSS · JavaScript — publicado na Vercel.
