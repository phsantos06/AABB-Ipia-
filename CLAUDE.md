# Site AABB Ipiaú-BA

Landing page estática (`index.html`) para o clube AABB de Ipiaú-BA.

## Deploy

- Repositório: https://github.com/phsantos06/AABB-Ipia-.git (branch `main`)
- Hospedagem: Vercel, projeto `paulo-d838/aabb-ipia` — https://aabb-ipia.vercel.app

## Permissão permanente (autorizada pelo usuário em 2026-09-06)

Sempre que o `index.html` for alterado, faça commit, push para o `main` e deploy
de produção na Vercel (`npx vercel --prod --yes`) automaticamente, **sem pedir
confirmação a cada vez**. O usuário pediu explicitamente para deixar esse fluxo
automatizado.
